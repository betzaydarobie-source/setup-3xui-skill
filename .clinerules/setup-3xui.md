# Cline 规则

本仓库用于安装和管理 3X-UI 面板，并生成后台资料和客户节点资料。

工作时请优先读取 `AGENTS.md`，并以其中的流程、安全规则和失败处理为准。

执行要求：

- 运行前确认用户提供必要的 VPS 或面板信息。
- 安装面板使用 `scripts/setup_3xui.py`。
- 添加客户使用 `scripts/add_3xui_client.py`。
- 重新生成后台文档使用 `scripts/make_3xui_doc.py`。
- 优先通过 `VPS_PASSWORD` 环境变量传递 SSH 密码。
- 不要把部署输出、后台资料、客户资料、节点链接、二维码、配置、日志或 `.env` 文件提交到 Git。
- 最终回复要说明任务结果；成功时返回必要产物；失败时说明失败步骤和已检查日志。
